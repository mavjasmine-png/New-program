Phase 3 · Release review

Version 3.4.0 · 25 October 2026

Finish your day on your terms. Session completion, completed exercises, skipped exercises and logged sets are now separate and visible.

Problems addressed

  • Early completion was hard to discover. Finish training for today now works directly with any amount of logged work.
  • Unticked work did not distinguish deliberate skips. Optional reasons, undo and history now make the record clearer.
  • Session mode and position were not reliably restored. Reload/resume retains the selected week/day, mode, alternative and last exercise.
  • Alternatives lacked useful setup context. Cards now compare equipment, movement focus and exercise-specific instructions before selection.
  • Small demonstrations were difficult to inspect. Enlarged scrollable views, synchronised step/image selection and a persistent close control improve access.
  • Embedded images made the media script unnecessarily large. A lightweight manifest now points to 92 deduplicated assets; all 65 guides remain included.
  • Offline and update status were unclear. Separate shell/visual readiness, progress, retry and backup/update controls expose the actual state.
  • Review found inaccurate load labels. TRX now uses bodyweight and dual cables use each-stack weights.

How completion is counted

An exercise counts as completed when all currently prescribed sets for the selected variation are ticked. A skipped exercise is counted separately even if some sets were logged. Actual logged sets from earlier variations remain in history.

A finished session can have remaining or skipped exercises. It counts towards the weekly finished-session indicator, while its history states that some work was not completed. Express counts the first three strength exercises. Changing work after finishing reopens the session.

Verification evidence

  • Programme, deload, history, date, backup and service-worker regression checks passed.
  • Empty, partial and full sessions finish and reopen without changing set records; a storage failure does not claim successful completion.
  • Skip/undo and exercise changes preserve earlier work. Interrupted media downloads report failure and retry only missing files.
  • All 65 guides map to two valid assets; all 130 image references rendered in the browser.
  • Browser interaction checks covered early finish, load entry, skip/undo, swap comparison, Express mode, reload/resume, history, visual enlargement and popup focus return.
  • 320px and 390px browser layouts were checked. Workout and popup content had no horizontal overflow; an enlarged image intentionally scrolls within its own viewer.

Tests are included as verify.cjs, verify-finish.cjs, verify-media.cjs and verify-offline.cjs. No QA records are bundled with the app.

Publication and remaining environment checks

Upload all supplied files using README.txt. The live GitHub site has not been changed. Export a backup first; close old app windows after deployment so the waiting update can activate.

Physical iPhone Safari, VoiceOver, installation, Files import/export and airplane-mode launch remain on-device acceptance checks. The HTTP preview cannot install the production service worker; cache/network behaviour was tested in controlled simulations. Do not read these results as a guarantee for an untested device or deployment.

Training and media scope

The existing seven-day structure, alternatives, conservative hinge effort, deload and eight-week review remain. No bar across the hips or travelling carries have been introduced. Photos and simplified illustrations support written coaching; they do not assess your movement or replace individual advice for persistent symptoms.

Optional videos remain a future enhancement. Media credits and background coaching references are in MEDIA_CREDITS.txt. Read the complete programme or return to the app to use its core/reset library.
